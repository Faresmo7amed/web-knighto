Working with bidirectional text

How to mix English and Arabic on one page without breaking punctuation, numbers or code.

By [Author name]Updated Oct 8, 20265 min readcssrtl

One page, two directions#

A page can run left to right and still hold right-to-left passages. Mark each Arabic passage with its own direction, like this word, مرحبًا بالعالم, so the browser orders the words correctly.

ARABIC PASSAGE · dir="rtl"
هذه فقرة عربية داخل صفحة إنجليزية. تُعرض من اليمين إلى اليسار، وتبقى المصطلحات التقنية مثل dir="rtl" من اليسار إلى اليمين.

Code stays left to right#

Code blocks never flip. Only the text inside the string changes direction.

index.html
<p dir="rtl" lang="ar">
  مرحبًا بالعالم
</p>

TipUse dir="auto" for text you cannot predict, such as comments written by visitors.

Common pitfalls#

  • Numbers and punctuation can jump to the wrong side
  • Icons that point forward must flip in right-to-left layouts
  • Margins and padding should use logical properties
  • قد تنتقل الأرقام وعلامات الترقيم إلى الجانب الخاطئ
