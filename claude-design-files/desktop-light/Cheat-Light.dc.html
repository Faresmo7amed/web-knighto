Array methods cheat sheet

The array methods you reach for most, grouped by what you want to do, with what each one returns.

By [Author name]Updated Oct 8, 20263 min readjavascriptcheat sheet
Mutating methodsThese change the original array: push, pop, shift, unshift, splice, sort and reverse. Everything else returns a new value.

Add and remove

MethodDoesReturns
push(x)Add to the end mutatesnew length
pop()Remove the last item mutatesremoved item
unshift(x)Add to the start mutatesnew length
shift()Remove the first item mutatesremoved item
splice(i, n)Remove or replace in place mutatesremoved items

Search and test

MethodDoesReturns
includes(x)Does it contain x?boolean
indexOf(x)First position of xindex or -1
find(fn)First item that matchesitem or undefined
findIndex(fn)Position of first matchindex or -1
some(fn) / every(fn)Any / all pass the testboolean

Transform

MethodDoesReturns
map(fn)Result of fn for each itemnew array
filter(fn)Keep items that passnew array
reduce(fn, init)Fold into one valueany value
sort(fn)Order the items mutatessame array
reverse()Flip the order mutatessame array

Combine and slice

MethodDoesReturns
slice(a, b)Copy a rangenew array
concat(b)Join two arraysnew array
flat(depth)Unwrap nested arraysnew array
join(sep)Turn into a stringstring
[...a, ...b]Spread into a copynew array
