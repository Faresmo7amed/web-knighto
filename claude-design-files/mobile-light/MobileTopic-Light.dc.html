Overview#

JavaScript runs in every browser and, through Node.js, on servers too. It adds behavior to a page: responding to clicks, loading data, and updating what the visitor sees without a reload.

This topic starts from the basics and builds up. Each page ends with a link to the next one, so you can read straight through or jump to what you need.

What you will learn#

  • How values, variables and types behave
  • How to write and reuse functions
  • How to work with objects and arrays
  • How asynchronous code is scheduled
