Color palette

Syntax highlighting

The eight owner colors are fixed in dark mode. Light counterparts keep the same hue but are darkened to pass AA on the light code surface. Keywords, numbers, comments and decorators are proposed.

  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount(count + 1)}>
      {`Clicked ${count}`}
    </button>
  );
}
